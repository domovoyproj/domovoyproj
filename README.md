# Привет 👋

Пишу на Rust, TypeScript и Python. Разбираюсь в многопоточке, работе с большими данными и интеграции AI. Делаю утилиты для себя и всё, что кажется полезным.

---

## Проекты

### 🤖 AI & инструменты

**[momp](https://github.com/domovoyproj/momp)** — веб + десктоп клиент для [Oh My Pi](https://github.com/can1357/oh-my-pi)  
Полная русская локализация, мониторинг лимитов моделей, файловый менеджер, автообновления. Next.js + Tauri.

**[RuHub (github-ru)](https://github.com/domovoyproj/github-ru)** — расширение для браузеров (Chromium)  
Русифицирует GitHub с защитой кода и кнопками быстрого доступа (Web VS Code, ZIP).

---

### ⚡ EPP Suite (Rust)

**[epp-api](https://github.com/domovoyproj/epp-api)** — центр управления лицензиями  
Actix-Web + SQLite. Привязка к железу, дистрибуция релизов, биллинг.

**[Xenos](https://github.com/domovoyproj/Xenos)** — обработчик больших баз  
3.5M+ строк/сек (150 МБ/сек). Дедупликация, фильтрация, нормализация с фиксированным RAM. Rayon + memmap2.

**[MCK](https://github.com/domovoyproj/MCK)** — многопоточная проверка почты  
IMAP/POP3/SMTP, автоопределение серверов, поиск писем. Tokio + WebView2.

---

### 📱 Helper (персональная PWA)

**[helper-app](https://github.com/domovoyproj/helper-app)** — всё-в-одном для телефона  
Калории и БЖУ по фото (Gemini AI), менеджер паролей (2FA/TOTP), бюджет, график смен, TikTok-загрузчик. Vanilla JS + CryptoJS, работает оффлайн.

**[helper-backup](https://github.com/domovoyproj/helper-backup)** — приватное облако для бэкапов  
Сквозное AES-256 шифрование на клиенте.

**[helper-files](https://github.com/domovoyproj/helper-files)** — файлообменник на GitHub  
Шаринг файлов до 15 МБ через CDN + TinyURL.

---

### 🔍 Парсинг

**[avito-parser](https://github.com/domovoyproj/avito-parser)** — мониторинг Авито  
Скоринг выгодности сделок через AI, веб-панель, уведомления в Telegram. FastAPI + Playwright + Docker.
